# Builds des évals

Les 4 builds « Moine Foudre » (1/4 à 4/4) servent aux évals 2 et 3 de `evals.json`. Ils ne sont plus dans
`builds/` pour ne pas être publiés avec le site.

Avant de lancer ces évals, copiez ces fichiers `.json` dans le dossier `builds/` du projet (ou, dans
l'interface, « Mes builds » → « Restaurer une sauvegarde » en choisissant chaque fichier).
