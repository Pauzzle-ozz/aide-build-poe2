# Glossaire EN → FR officiel (PoE2)

Les guides (maxroll, mobalytics, game8, poe.ninja, Reddit) sont en anglais ; le joueur lit le jeu en français.
Traduis toujours vers le terme **officiel** du client FR, sans laisser d'anglais ni de jargon dans le texte final.

**Source officielle prioritaire** : le glossaire du jeu intégré à l'outil (`data/glossary.json`, ~770 termes,
outil MCP `glossaire` ; `verifier_texte` signale le jargon). Ce fichier n'en est qu'un aide-mémoire hors ligne :
en cas de désaccord, le glossaire de l'outil a raison. Pour les noms propres (passifs, gemmes, uniques),
`rechercher_passifs` / `rechercher_gemmes` / `rechercher_objets` acceptent l'anglais et renvoient le nom FR.

## Pièges majeurs (les plus contre-intuitifs)

| Anglais | Français officiel | Remarque |
|---|---|---|
| Shock / Shocked | **Électrocution** / Électrocuté, « chances d'Électrocuter » | ≠ Electrocute ! |
| Electrocute | **Foudroiement** / Foudroyé, « Accumulation de Foudroiement » | altération à accumulation qui immobilise |
| Minions | **Créatures** (« Les Créatures ont… ») | pas « sbires » |
| X% increased | **X% d'Augmentation** de… | additif |
| X% reduced | **X% de Réduction** de… | additif négatif |
| X% more | **X% Davantage** de… | multiplicatif |
| X% less | **X% de Perte** de… | multiplicatif négatif |
| Gain X% of Damage as Extra Y | **Rajoute X% des Dégâts sous forme de Dégâts de Y** | « gain as extra » |
| X% of Damage Converted to Y | X% des Dégâts sont **Convertis** en Dégâts de Y | |
| Hit | **Touche** (« au Toucher », « Dégâts au Toucher ») | |
| Critical Hit | **Touche critique** ; Critical Damage Bonus = **Bonus de Dégâts critiques** | |
| Skill | **Aptitude** (gemme d'aptitude) | « compétence » toléré à l'oral |
| Passive skill / point | **Talent** passif / point de Talent | |
| Weapon Set (points) | **Ensemble d'armes** (Points de Talent d'Ensemble d'armes) | |
| Exposure | **Exposition** (malus de résistance, ex. Exposition à la foudre) | ≠ la malédiction Elemental Weakness = « Sensibilité aux éléments » |
| Magnitude | **Amplitude** (ex. Amplitude de l'Embrasement) | |
| Buildup | **Accumulation** (Gel, Étourdissement, Foudroiement, Verrouillage) | |
| Lucky / Unlucky | **Favorable / Défavorable** | |
| Ring | **Bague** | pas « anneau » |
| Invocation (Invoker) | **Évocation** / Sorts Évoqués ; Invoker = Évocateur | |
| Surpassing chance | chances **Cumulatives** | |
